# 故事局部改写（Story Rewriter）

一个可通过 Git URL 安装的 SillyTavern 前端扩展。它让你选中 AI 回复中的一小段文字，调用当前正在使用的模型生成候选改写，并在确认后只替换选中的片段。

> 当前版本：`0.1.0`（MVP）。建议先在非关键聊天中试用，并为重要聊天保留备份。

## 功能

- 在 AI 消息中选中文字后显示“局部改写”按钮。
- 输入自然语言修改要求，例如“事件不变，语气更克制”。
- 使用 SillyTavern 当前启用的模型和 API，不需要单独配置第二个模型。
- 生成结果先进入预览框，可手动修订后再确认替换。
- 只改动所选片段，保留消息其余内容。
- 支持立即撤销；开启持久化撤销后，每条有历史记录的消息也会显示撤销按钮。
- 兼容常见 Markdown 选区，包括强调、链接、实体字符和换行。

## 安装

1. 打开 SillyTavern 的“扩展”面板。
2. 选择“安装扩展”。
3. 输入仓库地址：`https://github.com/zhanglongyi99/sillytavern-custom-plugin`
4. 完成安装后刷新 SillyTavern。

需要 SillyTavern 1.17.0 或更高版本。该项目是纯前端扩展，不需要服务器插件、构建步骤或额外依赖。

## 使用

1. 在一条 AI 回复内选中需要修改的文字。
2. 点击选区附近出现的“局部改写”。
3. 填写修改要求并点击“生成候选”。
4. 检查或手动编辑候选内容。
5. 点击“确认替换”。如结果不满意，可使用提示条或消息工具栏中的撤销按钮。

## 设置

- `启用选区改写`：临时关闭或开启选区按钮。
- `单侧上下文字符数`：发送给模型的选区前后文长度，范围为 0–8000。
- `候选最大回复 token`：限制候选结果长度，范围为 64–4096。
- `把撤销记录写入聊天`：开启后，最近 5 次局部替换记录保存在消息数据里；关闭后仅在当前页面会话保存。

## 当前限制

- 仅支持普通 AI 消息，不处理用户消息、系统消息或跨消息选区。
- 如果消息使用了与原始文本不同的 `display_text`，为避免定位错误不会显示改写按钮。
- 选区映射覆盖常见 Markdown，但复杂 HTML、插件自定义渲染或非常规 Markdown 可能无法定位。
- 替换历史消息不会自动重新生成它后面的故事内容；后续消息可能需要手动调整。
- 模型仍可能返回超出要求的内容，请在确认替换前检查预览。

## 开发与检查

需要 Node.js 18 或更高版本：

```bash
npm run check
npm test
```

项目不需要安装 npm 依赖。核心结构：

```text
manifest.json       SillyTavern 扩展清单
index.js            扩展生命周期、界面和消息写回
settings.html       扩展设置面板
style.css           界面样式
lib/selection.js    可见选区到原始 Markdown 的定位
lib/rewrite.js      模型提示词和结果处理
tests/              无浏览器依赖的单元测试
```

# 故事局部改写（Story Rewriter）

一个可通过 Git URL 安装的 SillyTavern 前端扩展。它让你选中 AI 回复中的一小段文字，调用当前正在使用的模型生成候选改写，并在确认后只替换选中的片段。

> 当前版本：`0.2.1`。建议先在非关键聊天中试用，并为重要聊天保留备份。

## 功能

- 在 AI 消息中选中文字后显示“局部改写”按钮。
- 输入自然语言修改要求，例如“事件不变，语气更克制”。
- 使用 SillyTavern 当前启用的模型和 API，不需要单独配置第二个模型。
- 默认通过 SillyTavern 原生后台生成流程使用当前角色卡、激活的世界书、作者注、扩展提示和聊天历史。
- 右侧编辑工作台不会遮住聊天，可围绕同一选区连续提出多轮要求。
- 可以填写需要持续遵守的约束，恢复本次会话的旧候选。
- 原文与候选并排预览，候选可手动修订后再确认替换。
- 只改动所选片段，保留消息其余内容。
- 支持立即撤销；开启持久化撤销后，每条有历史记录的消息也会显示撤销按钮。
- 兼容常见 Markdown 选区，包括强调、链接、实体字符和换行。

## 安装

1. 打开 SillyTavern 的“扩展”面板。
2. 选择“安装扩展”。
3. 输入仓库地址：`https://github.com/zhanglongyi99/sillytavern-custom-plugin`
4. 完成安装后刷新 SillyTavern。

需要 SillyTavern 1.17.0 或更高版本。该项目是纯前端扩展，不需要服务器插件、构建步骤或额外依赖。

## 使用

1. 在一条 AI 回复内选中需要修改的文字。
2. 点击选区附近出现的“局部改写”。
3. 在右侧工作台选择上下文模式，并可填写需要持续保留的约束。
4. 填写第一轮修改要求，点击“生成候选”（也可按 `Ctrl/Command + Enter`）。
5. 检查候选；可以继续输入“再克制一点”等要求进行多轮调整，也可以恢复之前的候选。
6. 点击“确认替换”。如结果不满意，可使用提示条或消息工具栏中的撤销按钮。

### 上下文模式

- `完整酒馆上下文（推荐）`：通过 SillyTavern 的 quiet generation 流程生成。选区只决定最终改动范围；模型同时使用酒馆本次实际组装的角色、世界设定、作者注、扩展提示和聊天上下文。
- `局部快速模式`：只发送选区以及前后指定字符数，速度和消耗更低，但可能遗漏长期要求或较远剧情。

“完整”指酒馆在当前上下文窗口、世界书激活规则和提示词优先级下实际会发送的内容，不代表无条件发送世界书中的全部条目。

## 设置

- `启用选区改写`：临时关闭或开启选区按钮。
- `默认上下文模式`：新建编辑会话时默认使用完整酒馆上下文或局部快速模式。
- `局部参考文字数（单侧）`：仅用于局部快速模式，范围为 0–8000。
- `候选最大回复 token`：限制候选结果长度，范围为 64–4096。
- `把撤销记录写入聊天`：开启后，最近 5 次局部替换记录保存在消息数据里；关闭后仅在当前页面会话保存。

## 当前限制

- 仅支持普通 AI 消息，不处理用户消息、系统消息或跨消息选区。
- 如果消息使用了与原始文本不同的 `display_text`，为避免定位错误不会显示改写按钮。
- 选区映射覆盖常见 Markdown，但复杂 HTML、插件自定义渲染或非常规 Markdown 可能无法定位。
- 替换历史消息不会自动重新生成它后面的故事内容；后续消息可能需要手动调整。
- 完整模式修改历史消息时会参考目标消息之后的现有剧情，以尽量避免冲突；暂不支持“只看到目标消息及其之前内容”的时间线截断模式。
- 世界书仍遵循酒馆自己的关键词激活和 Token 预算，未激活或被上下文裁剪的资料不会强制发送。
- 完整模式的耗时和上下文消耗接近一次正常的酒馆后台生成，并可能触发其他扩展注册的生成钩子。
- 模型仍可能返回超出要求的内容，请在确认替换前检查预览。
- 插件会优先要求结构化 JSON，并过滤常见思维标签、system-reminder 和编辑契约回显；如果模型仍未返回有效 `replacement`，会停止并提示，不会把回显内容写入聊天。

## 开发与检查

需要 Node.js 18 或更高版本：

```bash
npm run check
npm test
```

项目不需要安装 npm 依赖。核心结构：

```text
manifest.json       SillyTavern 扩展清单
index.js            扩展生命周期、界面和消息写回
settings.html       扩展设置面板
style.css           界面样式
lib/selection.js    可见选区到原始 Markdown 的定位
lib/rewrite.js      模型提示词和结果处理
tests/              无浏览器依赖的单元测试
```

# 全文审阅显示

工具栏增加“显示全文”开关，默认关闭并保存偏好。开启时切回“全部”，按现有对齐顺序在修改块之间显示未修改段落，包括文首和文尾。连续未修改段落合并为中性只读区，不参与确认计数、采用按钮或上/下修改导航。正文使用 textContent，不执行正文中的 HTML。

选择“计划内”或“疑似越界”时退出全文显示，避免过滤后仍误以为正在查看完整文章。开关只改变显示，不重新计算对齐、生成请求或采用决定；上下/左右对照及高亮开关保持原样。

验证：128 项自动测试通过，语法和入口导入检查通过。覆盖首中尾未修改段落、连续段落合并、增删块顺序、字面 HTML 和开关不修改采用决定。未进行浏览器视觉验收，未推送或更新安装目录。

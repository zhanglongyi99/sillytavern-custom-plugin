# v0.7.8 工作台悬浮气泡

## 用户问题

侧栏即使调到最窄仍会占用较大正文宽度。长文本生成和逐块确认期间，用户需要继续阅读原消息，但又不能关闭工作台，否则会丢失当前会话或取消正在进行的生成。

## 产品行为

- 标题栏新增“最小化为悬浮气泡”。
- 最小化后只保留右下角 56px 气泡，释放正文阅读空间。
- 最小化不会关闭工作台，不会清除要求、候选、审核决定或失败尝试。
- 生成期间也允许最小化和恢复；气泡状态点会以脉冲表示任务仍在运行。
- 点击气泡恢复最小化前的工作台状态；如果此前处于最大化，恢复后仍保持最大化。
- 关闭仍是独立动作，并继续遵循原有的生成取消行为。

## 验收

1. 空闲时最小化，正文区域不再被侧栏覆盖，点击气泡可恢复。
2. 生成中最小化，生成不中断，气泡显示忙碌动画。
3. 生成结束后从气泡恢复，候选、状态和逐块选择均保留。
4. 桌面与移动布局中气泡均位于输入区上方，不覆盖整片正文。

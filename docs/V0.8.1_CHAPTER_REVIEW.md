# v0.8.1 整章审阅与原文定位

问题：检查轮已经包含完整消息，但单段工单导向弱化了跨模块统筹；修订轮只有原文与 P 编号，缺少显式对应关系。

调整：审阅输入按顺序提供完整 chapterText，要求先通读整章、核对同一事件的跨段一致性，将同一根因合并报告。每项提供整章修改意见与真正需要同步修改的关联段落；无需修改的内容不列为问题。

仅有证据的明确问题进入修订，待确认和风格建议不混入自动修改指令。自然语言修订意见带原文摘录和证据；普通生成、精简恢复和续接均携带目标段落的编号与完整文字映射。关联区域进入原有差异审核计划。

报告先展示本篇整体修改意见，再展示详细证据。调用次数不增加。完整输入不代表模型必然认真阅读或判断正确，仍由用户确认最终采用。

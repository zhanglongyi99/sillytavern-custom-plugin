# v0.8 一键检查与修订

入口位于修改工作台，检查整条回复或当前合成稿。用户可选择只检查或检查后生成修订候选。默认检查并修订；无明确问题则结束，不保存消息。正常调用为检查、修订两次；缺资料时允许一次本地历史补查及一次复审，共三次。格式重试和长文续接另计。

检查使用酒馆完整上下文（降级时明确提示）、完整待审正文、最近六条前序消息、玩家本轮要求、可持久保存的检查要求、编辑约束及召回证据。历史查询最多三条、最多一轮，受资料预算约束。报告展示依据和未确认问题；没有有效段落位置或可验证证据的条目不自动修订。资料中的指令不具有新增规则的权力，未来计划不视为已发生事实。

检查报告直接生成影响计划，跳过重复影响分析；修订复用现有完整性、差异检查及 Swipe 保存流程。候选由用户确认应用，不默认第三次 AI 复查。不自动挂接消息生成事件。

保留消息附加元数据的现有行为；本版不声称支持任意自定义推理块格式的自动分离。报告要求不改分析、状态栏等非目标附加区，最终仍需逐块审核。原文版本、聊天或 Swipe 改变时中止本次检查。未覆盖的历史和缺证据项明确显示为待确认。

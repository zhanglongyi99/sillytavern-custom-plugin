# v0.4 产品层级重构规格

## 1. 目标

把故事改写从“多个技术选项”收敛成一个用户能直接理解的动作：指出问题、描述目标、生成一个保留原版本的新版本。

用户只需要回答两个问题：

1. 修改重点在哪里？通过选中文字，或直接修改整条回复。
2. 是否允许相关内容联动？仅改选区，或智能关联调整。

角色卡、世界书、长期任务、资料检索、影响分析、完整上下文和审计都属于插件内部策略，不作为普通用户的首要决策。

## 2. 入口

### 2.1 选中文字后

浮动工具条只显示一个按钮：`修改`。它打开“修改选中内容”工作台。

选区是初始关注范围，不自动决定是否允许圈外调整。

### 2.2 消息工具栏

每条 AI 消息保留一个按钮：`修改这条回复`。它打开同一个工作台，但没有预选文字，由 Agent 根据用户要求识别修改重点。

## 3. 工作台

工作台首屏只显示：

- 当前目标（选中内容或整条回复）。
- 本轮修改要求（必填）。
- 修改范围：`智能关联调整`（默认）或 `仅改选区`。
- `必须保留`（可选折叠项）。
- `生成新版本`。

### 3.1 修改范围

`仅改选区`对应旧的精确替换：只返回并写回选区文字，圈外不变。

`智能关联调整`对应旧的柔性重构：生成完整消息，允许修改与目标直接相关的伏笔、因果、结果和必要衔接，但保护无关内容。

旧的“严格局部/语义关联/广泛重构”不再作为用户选项。影响范围由 Agent 根据要求识别，必要时由风险确认打断。

### 3.2 无选区模式

“修改这条回复”使用智能关联调整流程。用户要求决定关注范围；整条消息作为候选基线，而不是默认把所有段落当成强修改区。

## 4. 上下文策略

普通 UI 不再显示“完整酒馆上下文/局部快速模式”。插件默认使用酒馆完整上下文，并补充当前完整消息和按需检索的角色、世界书、聊天资料。

只有完整生成接口不可用时才自动降级到局部生成，并在工作台状态中明确提示。高级设置可为兼容或排障强制使用插件资料模式；旧设置值继续读取，但升级到 v0.4 时默认迁移回完整酒馆上下文。

## 5. 生成流程

1. 理解修改要求并识别影响范围。
2. 查阅相关角色、世界书和历史资料。
3. 生成候选新版本。
4. 执行本地 Diff、保护事实和越界审计。

默认不要求用户逐段确认影响范围。只有发生高风险情况时才提示确认。

审计是决策辅助，不是权限系统。即使候选存在明显截断、保护事实冲突或大范围疑似越界，界面也必须列明风险并允许用户确认后应用；只有候选为空、源消息已变化或写入失败等技术性不安全状态可以阻止操作。

## 6. 结果界面

候选区默认展示完整可编辑的新版本，并在顶部给出摘要。

“查看修改”折叠区合并原“重点变化”和“影响范围”。“使用的资料”作为高级折叠区展示来源和预算裁剪。

## 7. 保存

主要动作统一为 `应用为新版本`，保存为新 Swipe，原版本始终保留。

覆盖当前消息保留为高级危险操作，不占据主按钮区域。

## 8. 设置

普通设置只保留启用开关。输出长度、资料预算、分析预算和调试参数移动到“高级设置”。旧配置兼容读取，但不再暴露为首屏决策。

## 9. 旧功能映射

| 旧功能 | v0.4 处理 |
| --- | --- |
| 精确替换 | 修改选中内容 → 仅改选区 |
| 柔性重构 | 修改选中内容 → 智能关联调整 |
| 全文方向重构 | 修改这条回复 |
| 严格局部/语义关联/广泛重构 | 删除用户选项，改由 Agent 识别 |
| 完整酒馆上下文/局部快速模式 | 默认内部策略，局部模式仅自动降级 |
| 生成前确认影响范围 | 改为高风险时按轮次触发 |
| 保存为新 Swipe | 改名为应用为新版本 |
| 替换当前消息 | 移入高级操作 |

## 10. 验收标准

- 选区浮动工具条只有一个“修改”按钮。
- 工作台不要求用户理解上下文模式或三档影响强度。
- 选区任务可以在“仅改选区”和“智能关联调整”之间选择。
- 无选区任务使用同一工作台和生成流程。
- 默认保存为新 Swipe，原文可随时切回。
- 完整酒馆上下文、世界书和长期约束默认参与生成。
- 高级参数仍可兼容旧配置，但不干扰普通使用。

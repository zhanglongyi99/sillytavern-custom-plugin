# 结构化检查空返回修复

最新 0.8.2 记录：检查首轮接口返回 2 字符，重试返回 0 字符；尚未修订正文。旧日志只能看到酒馆清理后的字符串，无法确认上游原始响应。

实施：检查和影响分析禁用 quiet 接口自动推理清理，在本地移除显式推理块后优先解析报告；仅在失败时尝试配置解析器。不能从推理块提取报告，不输出或记录推理正文。有效报告仍须经过现有结构与证据验证，不补齐损坏 JSON、不把空报告当作无问题。

日志记录接口返回长度、本地清理长度、配置清理长度（如调用）、解析路径或错误分类，不声称是供应商原始长度。区分空返回、清理后为空、JSON 不完整、非 JSON、结构无效。两次调用上限保持不变，第二次移除 Schema 并按错误类别提示；错误提示不推定推理开关或输出额度是原因。

验证：空串、短返回、截断、纯 JSON、围栏、显式推理加报告、只有推理、未闭合推理、配置误清理、结构错误及日志隐私。真实服务商响应仍需用户后续复测。

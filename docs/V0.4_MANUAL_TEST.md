# v0.4 手工验证清单

## 1. 选区修改

1. 在 AI 回复中选中一段文字。
2. 确认浮动工具条只显示“修改”。
3. 打开工作台，确认出现“智能关联调整”和“仅改选区”。
4. 使用“仅改选区”生成并应用，确认只替换选区且应用为新版本。
5. 切回旧 Swipe，确认原文仍然存在。
6. 在长回复中向下拖选并触发自动滚动，跨过至少一个视口后释放，确认“修改”按钮仍会出现。
7. 保持选区滚动页面，确认停止滚动后按钮会在当前可见选区附近恢复。

## 2. 智能关联调整

1. 粗略选中涉及某个人物线的一个或多个段落。
2. 输入“重新梳理这条人物线，其他人物设定保持不变”。
3. 使用默认的“智能关联调整”生成新版本。
4. 确认候选是完整消息，且修改摘要能区分重点变化和关联调整。
5. 手动编辑候选后确认审计结果会更新。

## 3. 修改整条回复

1. 点击 AI 消息工具栏的“修改这条回复”。
2. 确认工作台显示“自动识别修改重点”，而不是把全文提示为必须重写。
3. 输入具体人物线或结构目标，确认无选区也能生成完整候选。

## 4. 上下文与资料

1. 确认普通工作台不再显示上下文模式和三档影响强度。
2. 使用包含角色卡、世界书和长期约束的聊天生成，确认资料来源出现在“使用的资料”中。
3. 在高级设置中确认预算项仍可调整，旧配置不会丢失。

## 5. 版本安全

1. 确认主按钮文案为“应用为新版本”。
2. 确认原回复没有被覆盖，原生 Swipe 可以返回旧版本。
3. 在候选为空、消息发生变化或审计阻断时，确认不会写回聊天。

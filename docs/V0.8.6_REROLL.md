# 本轮重 Roll

每个新生成候选保存该轮的生成任务快照（工作稿、要求、约束、检索依据、影响计划和历史要求）。点击重试从该快照生成，不使用失败候选作为底稿，不把输入框未提交文字带入，不重跑影响分析或审阅。当前宿主预设/世界书仍由酒馆提供，不保证整个网络请求逐字相同。

旧候选保留，新增候选标记来源轮次。失败或取消恢复原候选及选择；未提交输入保留。旧版本没有任务快照的候选不提供重试入口。沿用会话最多八个候选的上限，不新增无限缓存。

验证：119 项测试及语法/入口导入检查通过。新增测试执行重 Roll 协调函数，覆盖完整修改和局部替换使用已保存底稿、未提交要求保留、旧候选保留、失败/取消恢复选择以及并发阻止。未调用真实模型，未进行浏览器视觉验收；未推送或覆盖酒馆安装目录。

# v0.7.11 可选文字差异高亮

对照工具栏新增“高亮变化”切换按钮，默认开启，偏好随插件设置保存。适用于所有审核块及上下、左右两种布局，不绑定模型、预设或角色。

原文被删除或替换的部分用红色背景与删除线标记；候选新增或替换的部分用绿色背景与下划线标记。关闭只移除标记，不重建审核界面，因此保留滚动、展开和采用状态。显示文本使用 textContent，HTML 按原字符串显示，不执行。

比较使用 Unicode 码点级最长公共子序列，先剥离相同首尾；大段重写超过计算预算时高亮整个不同区域，避免长文阻塞页面。高亮只影响显示，不参与段落定位、采用决策和最终保存。

验收：逗号改句号只突出标点；新增和删除正确落在对应一侧；关闭后原样显示；重新打开工作台沿用偏好；保存文本不含高亮标签。

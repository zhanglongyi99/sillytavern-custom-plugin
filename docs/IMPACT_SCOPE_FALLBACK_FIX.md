# 影响分析降级范围修复

影响分析失败或未识别重点时，仍保留正文生成能力，但备用范围不再视作修改授权。包括历史重 Roll 快照在内，fallback 方案中的变化统一显示为“范围未确认”，不伪装成“计划内”或已证实的“疑似越界”。默认保留原文；逐块确认、全部采用仍可显式选择。

审阅增加“范围未确认”过滤，计划内过滤及批量采用排除未确认变化。成功生成后仍保留分析未完成的提示，并切回全部变化，避免因先前的计划内过滤隐藏整份候选。诊断单独记录未确认变化数量和范围分析状态。

重 Roll 正常范围方案不增加调用；旧方案降级时，使用保存的本轮输入重新执行影响分析。成功后恢复正常分类，失败或空重点继续保持未确认，不循环重试；取消沿用旧候选及选择恢复机制。

本次不修改宿主、供应商请求协议或其他并行开发中的用量观察功能，也不承诺消除上游 inference_failed。仅修复错误之后的安全降级与审阅行为。

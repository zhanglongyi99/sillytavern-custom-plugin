# 酒馆结构化返回透传

已确认本地宿主在 JSON Schema 模式中默认将解析失败结果替换成 `{}`；`returnInvalid: true` 可让支持此选项的宿主返回未解析文本。首轮检查和影响分析、原始接口降级均使用复制后的 Schema 开启此选项，不修改共享 Schema。

保留第二次不带 Schema 的兼容请求，不改变预设或全局正则。日志标记实际调用接口、Schema 透传状态以及宿主普通文本清理风险。接口返回仍不是供应商原始响应；空对象单独分类，不能把它当作无问题报告。

边界：本地公开事件只有请求阶段，没有适用于 quiet 结果的响应处理前事件。普通文本 quiet 请求仍经过宿主 cleanUpMessage。为避免捕获其他扩展请求、破坏并发或泄漏内容，本版不拦截全局 fetch、不改宿主、不伪造原始结束原因和推理字段诊断。若透传后仍出现空文本，需另行取得宿主/服务商层的元数据再定位。

验证：模拟宿主默认 `{}` 回退与 returnInvalid 透传，合法 JSON、围栏 JSON、损坏 JSON、空对象及共享 Schema 不变性；不增加模型调用次数。

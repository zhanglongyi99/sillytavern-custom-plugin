# v0.7.7 长原文显示修复

## 问题

逐块确认把超过 700 字的原文放入默认关闭的 `<details>`。部分 SillyTavern 主题会隐藏浏览器原生展开箭头，界面只剩“原文 · N 字”的标题和空白区域，用户无法判断原文是折叠还是丢失。

## 修改

- 原文对照默认展开，不再按 700 字阈值自动关闭。
- 原文仍可手动折叠，保留长文本浏览能力。
- 隐藏不稳定的原生 marker，统一显示“▸ 展开 / ▾ 收起”。
- 候选栏和逐块采用逻辑不变。

## 验收

- 长原文首次进入逐块确认时正文可见。
- 点击“收起”后原文隐藏，再次点击可恢复。
- 当前主题是否显示原生 `<details>` 箭头不影响操作提示。

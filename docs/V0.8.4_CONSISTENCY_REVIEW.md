# 硬一致性优先审阅

先核对同一事件参与者、时间地点、物品流转、人物知情及信息传递，再核对外部要求，最后可选风格建议。完整本章保持不变，不增加默认调用。

连续性问题必须提交两个不同来源位置的逐字短引文、冲突说明、时间/视角等替代解释排查、可否确定统一依据。程序验证引文和位置存在，不声称能验证语义冲突。证据不完整或统一依据不确定的条目降为待确认，不自动修改。风格建议始终不进入自动修订。

展示报告按硬连续性、要求、格式、风格排序；向修订和补查传递双侧证据。仅作为依据的位置不自动列为修改目标。中性案例覆盖同行者矛盾、物品交接、重复信息与相对日期；测试只能证明协议和保护规则，真实召回率需模型复测。

验证结果：115 项测试、语法及入口导入检查通过。同行者及物品案例用于验证报告接收和双侧证据交接；重复信息和相对日期检查验证提示词规则存在，并未调用模型测量这些问题的实际召回率。缺失新分类字段的响应保留为待确认，避免兼容重试时旧结构被自动采用。开发目录版本 0.8.4，未推送或覆盖已安装目录。

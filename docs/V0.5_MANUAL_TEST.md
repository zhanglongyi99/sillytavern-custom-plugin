# v0.5 手工验收清单

## 1. 默认逐块决策

1. 对包含多段内容的 AI 回复执行“智能关联调整”。
2. 确认生成后默认打开“逐块确认”。
3. 确认强修改、关联修改和衔接调整默认勾选。
4. 确认疑似越界块默认不勾选，完整预览中对应段落保持原文。

## 2. 单块与批量操作

1. 分别切换修改、删除和新增块，确认完整预览立即变化且没有新模型请求。
2. 点击“仅采用计划内”，确认疑似越界块全部关闭。
3. 点击“全部采用”，确认完整预览包含模型提案的全部变化。
4. 点击“全部保留原文”，确认完整预览恢复原消息。
5. 确认“已采用 X/Y 项修改”与复选框同步。

## 3. 手工编辑

1. 在“新版本”中直接修改合成稿。
2. 返回“逐块确认”，确认差异块已按手工文本重建并默认采用。
3. 再关闭任意块，确认仍能从原文基线正确恢复。

## 4. 保存与多轮

1. 只采用部分修改后点击“应用为新版本”，确认新 Swipe 与完整预览完全一致。
2. 确认原 Swipe 可以切回。
3. 再提出一轮要求，确认新提案以当前合成稿为参考，但未授权块仍可单独拒绝。
4. 制造审计高风险，确认用户仍可在二次确认后保存或覆盖。

## 5. 长文本界面

1. 在桌面端拖动工作台左缘，确认宽度可在约 420px 到视口 96% 之间调整。
2. 确认完整预览为单栏大编辑区，不再显示拥挤的原文/候选双栏。
3. 确认宽屏差异卡原文和候选并排，窄屏改为单列。
4. 在手机宽度下确认工作台全屏、无横向溢出且隐藏拖宽手柄。
